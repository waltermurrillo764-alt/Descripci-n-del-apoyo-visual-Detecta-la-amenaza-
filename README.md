# Descripci-n-del-apoyo-visual-Detecta-la-amenaza-
Simulador web interactivo con 8 situaciones reales (phishing, smishing, vishing, USB, ransomware). El usuario decide si es legítimo o un ataque, recibe las señales de alerta explicadas y un puntaje final con recomendaciones. Diseño limpio, con barra de progreso, retroalimentación verde/roja y adaptable a celular y modo oscuro.
